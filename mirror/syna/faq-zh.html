Syna 常见问题（FAQ）

Mirrored from NUSV/Syna-NUSV · docs/faq/zh.md · synced 2026-09-18 16:52 UTC · original on GitHub

设备与连接

搜不到对方设备？

  • 确认两台设备在同一局域网（同一 Wi-Fi/路由器）；部分路由器阻挡 UDP 广播，请使用组播通道（自动启用）
  • 手机热点场景：设备接入同一热点；部分手机热点隔离客户端（AP 隔离），需在路由器设置中关闭
  • 点联系人页右上角"刷新"手动重播广播

连接失败 / 消息发不出？

  • 代理工具（Clash/FlClash 等）TUN 模式会劫持局域网流量：关闭 TUN 或把局域网网段加入白名单；Syna 已自动将本机互连走回环地址
  • 防火墙放行 Syna（Windows 首次启动提示；服务器需放行监听端口）
  • 服务器连接失败：确认地址端口、密码正确；内网穿透场景确认隧道已建立

消息显示"已发送"但对方没收到？

  • 离线消息会进入队列，对方上线自动补发；P2P 消息有 ACK 重传（3s×3）后入队列
  • 服务器群断线后消息标记为"失败"（红色），点击重发

Mirtazapine Shield

开启护盾后应用被锁定/误报？

  • 首次开启时可能对系统环境（厂商 ROM 库、ART JIT 缓存）误报——v0.9.8 起已对系统分区与 ART JIT 白名单校准
  • 锁定页会显示具体触发原因（如"可疑模块: 路径"），据此判断是否误报
  • 误报可解锁后反馈（GitHub Issues），附锁定页截图

忘记了解锁方式？

  • 生物识别是唯一解锁途径（桌面端为确认按钮）；未设置生物识别时点击解锁会提示先录入
  • 双重验证（TOTP）启用后需动态码；种子在设置页可查看

护盾关闭不了？

  • 关闭需生物识别 +（若开启）TOTP 动态码——这是防攻击者关闭的设计

服务器

如何搭建私人服务器？

  • 见教程「私人服务器」章节；macOS/Windows/Linux 均可用 java -jar syna-server.jar
  • 公网访问：frp / ngrok / Tailscale 任一映射端口即可

服务器安全建议

  • 修改默认密码 syna（-w 参数）
  • 服务器仅暴露 TCP 端口；建议通过 Tailscale 私有网络而非公网直连
  • 历史消息为 E2E 密文，服务器管理员无法读取消息内容（元数据可见）

数据与隐私

聊天记录存在哪里？

  • 本机加密存储（AES-GCM）；Android 密钥在 Keystore（TEE），桌面为 0600 权限密钥文件
  • 应用无任何导出/备份功能（设计如此，防数据泄露面）

卸载重装会怎样？

  • 本地数据随之删除且不可恢复；重新安装后为全新状态（设备身份变化会提示）
  • 加密密钥在 Keystore，卸载即销毁
