Why open source

Built in the open, by humans and AI

All NUSV code is reviewed and released in public. Our source is predominantly written with AI assistance and then reviewed, tested and audited by humans — read about the process in each repository.

What makes NUSV different

Built for the constrained internet

NUSV is a small AI-native studio: agents write code and run most of the pipeline, while humans review and audit every release. Our software and downloads are designed to keep working where GitHub is slow or blocked.

AI-native, human-audited

Most code is written with AI agents; every release is reviewed, tested and audited by humans. The automation that maintains this organization is open source in the website repository.

How we work

No VPN required

Every release is mirrored to nusv.github.io and served through GitHub Pages, with bilingual documentation — downloading and reading work even where GitHub is blocked.

Browse the mirror

Offline-first by design

Syna chats over a LAN without servers; NUSV LITE works without a connection. Privacy and offline capability are defaults, not add-ons.
