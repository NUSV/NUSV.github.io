The whole picture

How the pieces fit together

NUSV LITE is the front door to the ecosystem; the sync repository keeps its content fresh; Syna is our answer to privacy-first messaging; Gomoku is a standalone showcase of the stack we build with. All of them are built with Kotlin Multiplatform + Compose Multiplatform, so code and design patterns travel between projects.
